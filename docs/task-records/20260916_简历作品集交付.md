## 教训

- 不能只根据功能规划写简历：实现证据、测试证据与实际运行结果要分别核实。
- 模板替换会受到母版、主题字号、组合图形影响；历史成品也可能丢内容，必须看图再决定是否展示。
- 无真实测量时，价值描述使用具体操作收益，不虚构时间和效率百分比。
- Windows 高 DPI 会造成截图坐标偏差，截图进程需先启用 DPI 感知，并目视检查完整性。
- 截图辅助脚本的默认目录路径在本机报错，改用临时目录截图，再归档到交付目录。
- 作品集应标明历史截图和当前运行结果的来源，避免让招聘方误以为所有图片都来自同一版本。
