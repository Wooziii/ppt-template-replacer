# 简历项目描述｜PPT 模板替换工具

## 推荐版（可直接粘贴）

**PPT 模板替换工具｜Vibe Coding 独立项目**

围绕技术活动与企业培训中多份讲师 PPT 风格不统一、人工套版重复操作多的问题，通过 Vibe Coding 推进需求拆解、交互设计、AI 辅助开发与样本验证，完成 Windows 桌面工具原型。基于 Python、Tkinter、python-pptx 与 PowerPoint COM，实现单文件及批量模板替换、模板主题色与字体提取、标题识别、风险页标记及前后对比报告，将分散的版式调整操作整合为可重复执行的处理流程，帮助活动运营统一品牌表达，并通过可编辑 PPTX 输出与风险提示支持后续人工精修。

## 分点版（适合产品 / 运营 / AI 应用岗位）

- **场景洞察：** 从活动筹备中的讲师材料标准化需求出发，将模板选择、内容适配、效果检查和结果交付拆解为完整流程。
- **产品落地：** 通过 AI 辅助编程完成 Windows 桌面原型，设计“一键替换 / 批量替换 / 模板管理”三类操作入口，支持拖拽文件与本地处理。
- **质量闭环：** 引入标题识别、主题提取、复杂页面风险标记、COM 异常重试与回退，以及对比图和报告，便于定位需要人工复核的页面。
- **交付能力：** 提供源码、Windows 可执行程序、样例与测试；本次源码检查中 20 项既有自动化测试全部通过。

## 一句话价值

把活动 PPT 的重复套版工作做成可复用的本地工具，让运营人员集中检查复杂页面，降低统一品牌样式时的操作负担。
